# RFC 0002 — Spec v1

Summary
- Establish `/spec/**` schema: `ui.json`, `logic.json`, `data.json`, `theme.json`, `overlays.json`, `tests.json`, `meta.json`, `analysis.json`.

Principles
- UI is truth; proposal-only writes via RFC6902.

Schema (high level)
- ui.json: { screens[], frames[] }
- logic.json: { agents[], policies{} }
- data.json: { models[], rag: { indices[] } }

Migration
- Introduce spec store and keep localStorage UI state until replaced by kernel store.
